| الحقل | القيمة |
| --- | --- |
| التاريخ | 2026-10-31 |
| نوع العمل | تدقيق قراءة فقط + تشغيل اختبارات وفحوصات محلية |
| الفرع/الالتزام | لم يُتحقق عبر Git في هذه المهمة؛ تنفيذ Git ممنوع |
| بيئة الفحص | Windows (المضيف الحالي)، Node `v26.8.2`، pnpm `10.18.3`، Rust `1.99.1` |

### 2.3 ما لم يُتحقق

- لم تُنفَّذ أي عملية Git: لا `status`، ولا `log`، ولا `branch`، ولا `gh`.
- لم يُعد التحقق من نجاح CI على GitHub أو من حالة PR #4. سجل المشروع يشير إلى أن Phase 1 في PR مفتوح، لكن ذلك **غير مُعاد التحقق** هنا.
- لم تُشغّل نافذة Tauri (`tauri dev` أو `tauri build`) بصريًا.
- لم يُبنَ مثبّت، ولم تُختبر الترقية/الإلغاء/التوقيع.
- لم يُختبر أي اتصال شبكة حقيقي، ولا محرك فيديو، ولا متصفح.
- لم تُقس أداءات بدء التشغيل/الذاكرة/السرعة.
- لم تُفحص لقطات RTL/LTR بصريًا بدرجة كافية للحكم على التخطيط.
- لم تُشغّل اختبارات E2E أو accessibility أو visual regression.

## 5. ما يمكن اعتباره `VERIFIED` الآن

`VERIFIED` هنا محدود بالنطاق المختبَر، وليس شهادة على المنتج:

1. **بناء الواجهة وفحص الأنواع واللينت:** نجحت الأوامر أعلاه محليًا.
2. **تكافؤ مفاتيح i18n:** الاختبار يثبت تطابق مفاتيح `ar` و`en`، وعدم وجود ترجمات فارغة، وتطابق placeholders.
3. **منع النصوص الصلبة:** الاختبار يفحص ملفات `src` (باستثناء `test` و`i18n`) ولا يجد العربية أو نص JSX حرفيًا أو خصائص وصفية حرفية.
4. **CSS منطقي:** لا توجد خصائص `left/right` فيزيائية أو `text-align: left/right` أو `float` في `styles.css`.
5. **اللغة الافتراضية والتبديل في jsdom:** العربية RTL افتراضيًا، والتبديل إلى الإنجليزية يحدّث `dir`/`lang` ويحفظ الاختيار محليًا.
6. **تحقق الإعدادات:** الحالات الصالحة/غير الصالحة المختبرة في JS وRust تنجح/تفشل كما هو متوقع.
7. **تخزين SQLite المكتبي:** إنشاء القاعدة، الترحيل، الحفظ/القراءة، البقاء بعد إعادة الفتح، رفض الإعدادات غير الصالحة، الصف الواحد، وترحيل متكرر.
8. **بناء Rust:** `cargo fmt` و`clippy` و`test` و`build` نجحت محليًا.

لا يشمل ذلك: نافذة Tauri، SQLite عبر IPC، المظهر على نظام حقيقي، الوصول بقارئ شاشة، RTL بصريًا، الشبكة، التنزيل، المثبّت.

## 6. ما هو `TESTED` لكن ليس `VERIFIED` من طرف إلى طرف

| العنصر | سبب عدم كفاية الدليل |
| --- | --- |
| حفظ الإعدادات في SQLite | اختبارات مكتبية تستخدم قاعدة مؤقتة، لا أمر Tauri داخل التطبيق |
| تحميل الإعدادات عند بدء التطبيق | يختبر localStorage فقط، لا `get_settings` عبر IPC |
| تبديل اللغة واستمراره | يختبر jsdom/localStorage، لا حفظ SQLite وإعادة تشغيل النافذة |
| المظهر الداكن | يختبر `data-theme` فقط، لا CSS/تباين/نظام |
| RTL/LTR | يختبر `dir` وCSS، لا التخطيط الفعلي أو النص الطويل |
| منع الشبكة | يختبر عرض shell، لا منع الشبكة في محرك مستقبلي |
| CI | يختبر الإعداد، لا نعلم إن كان أخضر حاليًا على GitHub |

## 7. الميزات الناقصة

### 7.1 ناقص داخل نطاق المرحلة 1

- تشغيل نافذة Tauri موثق ولقطة/سجل.
- اختبار تكامل Tauri ↔ SQLite ↔ React.
- اختبار فشل حفظ اللغة من زر الترويسة، أو إصلاحه ليعرض خطأ.
- اختبار وصول آلي (axe) وتباين.
- اختبار النص العربي الطويل والجمع والأرقام.
- مراجعة بصرية موثقة للقطات RTL/LTR.
- قرار بشأن اختلاف تحقق مسار التنزيل بين الواجهة (Windows-only) وRust (host-absolute).
- مزامنة/نسخ احتياطي/رجوع لقاعدة البيانات.
- فحص تبعيات/أسرار أوسع (cargo audit/pnpm audit/SAST).

### 7.2 ناقص خارج نطاق المرحلة 1

- محرك HTTP، التسريع، الاستئناف، الإلغاء، إعادة المحاولة.
- إدارة الملفات، التحقق، المساحة، التكرار، التعارضات.
- نموذج المهام الموحد، الطابور، الجدولة، السجل، الاستعادة.
- محرك الفيديو و`ffmpeg`، القوائم، الترجمات، الصوت.
- زاحف الصفحة الواحدة و`robots.txt`/SSRF.
- إضافة المتصفح وNative Messaging.
- UX النهائي، tray، إشعارات، اختصارات، وصول.
- AI، الأمان الشامل، التشخيص، QA، التغليف، التوقيع، التحديث.

### 8.1 مخاطر المعمارية

- **نموذج المهام غير موجود:** كل ميزة قادمة ستحتاج Task model؛ تأخيره يجعل كل محرك يخترع حالته.
- **الخلط بين «المخطط» و«المنفذ»:** `ARCHITECTURE.md` يصف محركات وجسرًا غير موجودة؛ يجب تمييز الحالة في كل قسم.
- **الاعتماد على sidecars:** `yt-dlp`/`ffmpeg` يضيفان تراخيص وتحديثًا وحجمًا وسطح هجوم.
- **Native Messaging:** أعلى سطح هجوم، ويحتاج تحققًا صارمًا واختبارات عقد.
- **AI:** إن أُضيف قبل استقرار النواة سيزيد التعقيد والخصوصية بلا قيمة أساسية.

### 8.2 مخاطر المنتج

- الإفراط في الوعود بـ«كل المواقع» أو «كل الجودات» أو «سرعة مضمونة».
- تضخم v1 بميزات لا يمكن اختبارها جيدًا.
- اعتماد قانوني غير واضح على محرك/منصة.
- تجربة تثبيت سيئة بسبب توقيع غير متوفر.
