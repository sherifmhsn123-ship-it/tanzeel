## 1. تعريف الإصدار

`v1.0.0` هو أول إصدار مستقر عام لويندوز، يقدّم مدير تنزيل عربيًا أولًا، مع:

- تنزيل مباشر موثوق ومتعدد الاتصالات.
- طابور وجدولة واستئناف واستعادة.
- فيديو من مصدر مدعوم واحد على الأقل، مع الحالات المتقدمة المعتمدة.
- التقاط من المتصفح بفعل المستخدم.
- سحب روابط محدود من صفحة واحدة.
- واجهة عربية/إنجليزية كاملة.
- أمان وخصوصية وتشخيصًا وجودة وتغليفًا.

**ليس:** نسخة من «زاجل» أو IDM، ولا خدمة سحابية، ولا متجر، ولا دعم «كل المواقع».

## 2. المطلوب في v1.0

### 2.1 أساس التطبيق

| الميزة | معيار القبول | الحالة الحالية |
| --- | --- | --- |
| تطبيق Tauri يفتح | تشغيل نافذة موثق على Win10/11 | `IMPLEMENTED`، لم يُختبر بصريًا |
| عربية RTL افتراضيًا | `dir=rtl` وواجهة كاملة | `TESTED` جزئيًا |
| إنجليزية فورية | تبديل بلا إعادة تشغيل | `TESTED` جزئيًا |
| تكافؤ 100% | لا مفاتيح ناقصة/فارغة/placeholders مختلفة | `VERIFIED` في الاختبار |
| إعدادات محفوظة | لغة/مظهر/مجلد بعد إعادة التشغيل | `TESTED` مكتبيًا فقط |
| إعدادات آمنة | تحقق مزدوج، لا مسار خارج النطاق | `TESTED` |
| وصول أساسي | تسميات/تركيز/قارئ شاشة | غير مكتمل |

### 2.2 التنزيل المباشر والتسريع

| الميزة | معيار القبول |
| --- | --- |
| HTTP/HTTPS | تنزيل ملفات مباشرة فقط، رفض مخططات أخرى |
| اتصال واحد | مسار أساسي مضمون |
| متعدد الأجزاء | فقط عند `Range`/`206`/حجم صالح |
| استئناف | بعد انقطاع/إغلاق، دون تلف |
| إيقاف/استئناف/إلغاء | حالات واضحة وتنظيف آمن |
| إعادة محاولة | أخطاء عابرة فقط، بحد وتباعد |
| تقدم/سرعة/ETA | تحديث مخفف، دقة معلنة |
| حدود | كلية/لكل مضيف/لكل مهمة |
| أسماء آمنة | Windows/Unicode/عربية/محجوزة |
| تحقق | حجم/بصمة عند الإمكان |
| مساحة/صلاحيات | فحص وأخطاء واضحة |
| بدون شبكة في الاختبارات | خادم وهمي فقط |

### 2.3 الطابور والجدولة والسجل

- نموذج مهمة موحد.
- طابور أولوية وحد تزامن.
- إيقاف/استئناف الكل.
- جدولة داخل التطبيق (ما دام يعمل).
- سياسة فائت واضحة.
- استعادة بعد إعادة التشغيل.
- سجل بحث/تصفية/تصدير/حذف.
- حذف السجل لا يحذف الملفات.
- منع تكرار/تعارض المسار.

### 2.4 الفيديو والصوت

**الملتزم حاليًا وفق PRD:**

- مصدر واحد مدعوم (يوتيوب أولًا).
- عرض الصيغ المتاحة فقط.
- اختيار فيديو/صوت/جودة.
- دمج عبر `ffmpeg` عند الحاجة.
- قوائم تشغيل واختيار عناصر.
- ترجمات بلغات مختارة.
- صور مصغرة كبيانات.
- استخراج صوت/تحويل بصيغ محددة.
- فشل جزئي لعنصر لا يفشل الكل.
- أسماء/قوالب آمنة.
- لا DRM/محتوى خاص/تجاوز حماية.

**تحذير نطاق:** القوائم/الترجمات/الصوت تزيد المسار الحرج. إذا أراد المالك إصدارًا أسرع، يمكن تأجيلها إلى `v1.1` بقرار مكتوب؛ لا تُحذف بصمت.

### 2.5 سحب الموقع

- صفحة واحدة، HTML ثابت، نطاق أصلي، عمق 1.
- حد 200 رابط افتراضيًا.
- `robots.txt`، حد معدل، `User-Agent`.
- منع SSRF/العناوين الخاصة.
- مرشح نوع/امتداد.
- معاينة/تأكيد قبل التنزيل.
- إلغاء آمن.
- لا JS، لا cookies، لا paywall.

### 2.6 تكامل المتصفح

- إضافة MV3 لمتصفح Chromium واحد على الأقل.
- Native Messaging فقط، بلا منفذ.
- التقاط بفعل مستخدم فقط.
- تعطيل افتراضي.
- تحقق صارم من الرسالة.
- معاينة/تأكيد قبل المهمة.
- إزالة التسجيل عند الإلغاء.
- عدم قراءة تاريخ التصفح/التنزيلات.

### 2.7 تجربة المستخدم

- شاشات واضحة ومتسقة.
- RTL/LTR كاملان.
- حالات فارغة/تحميل/خطأ.
- إشعارات قابلة للإيقاف.
- tray اختياري.
- اختصارات لوحة مفاتيح.
- بحث/تصفية.
- نصوص عربية طويلة.
- أرقام/تواريخ.
- وصول أساسي.
- لا فتح ملف تلقائي.

### 2.8 الأمان والخصوصية

- threat model معتمد.
- تحقق URL/SSRF.
- مسارات آمنة.
- عمليات خارجية معزولة.
- جسر مقيد.
- أسرار DPAPI عند الحاجة.
- سجلات منقحة.
- لا تتبع/قياس افتراضي.
- تحديثات موقعة.
- فحص تبعيات/أسرار.
- حذف/تصدير.
- لا بيانات للمشروع.

### 2.9 التشخيص

- سجلات منظمة دوارة.
- حزمة تشخيص محلية منقحة.
- لا إرسال تلقائي.
- تعطيل السجلات التفصيلية.
- مقاييس أداء محلية.

### 2.10 التغليف

- مثبّت NSIS per-user.
- توقيع إن توفر، وإعلان غير موقّع بصراحة إن لم يتوفر.
- تحديث موقّع/مصدر رسمي.
- تراجع.
- إلغاء تثبيت آمن.
- checksums/SBOM/تراخيص.
- ملاحظات عربية/إنجليزية.
- بناء من GitHub فقط.

## 4. خارج نطاق v1.0

- DRM أو تجاوز حماية.
- محتوى مدفوع/خاص دون حق.
- تجاوز حظر جغرافي أو شروط منصة.
- ضمان «كل المواقع/كل الجودات».
- سرعة مضمونة.
- منفذ localhost لجسر المتصفح.
- التقاط خفي/مراقبة تاريخ.
- زحف متعدد الصفحات/نطاقات أو JS.
- مشغل وسائط/محرر فيديو.
- مزامنة سحابية/حساب.
- خدمات مصغرة/خادم مركزي.
- تنفيذ ملفات منزلة.
- دعم macOS/Linux كإصدار عام (CI فقط).
- Microsoft Store/ARM64.
- بيع/إعادة توزيع المحتوى.

## 7. موانع الإصدار

أي واحد مما يلي يمنع `v1.0.0`:

- فشل اختبار أمني حرج.
- فقدان بيانات/تلف صامت.
- فشل التثبيت/الترقية على جهاز نظيف.
- تحديث يقبل توقيعًا خاطئًا.
- ثغرة SSRF/path/command.
- سر مكشوف.
- فشل RTL/LTR الأساسي.
- مفاتيح ترجمة ناقصة.
- عيب P0/P1 مفتوح.
- ادعاء ميزة غير مختبرة.
- غياب موافقة المالك.
- نطاق غير معتمد.
- تبعية حرجة غير مراجعة.
