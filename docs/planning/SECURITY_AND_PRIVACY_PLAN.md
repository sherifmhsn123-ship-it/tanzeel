## 3. نموذج التهديد المختصر

| التهديد | مثال | الأثر | الضوابط |
| --- | --- | --- | --- |
| SSRF | رابط إلى `localhost` أو IP خاص | وصول لشبكة داخلية | منع العناوين الخاصة، تحقق التحويلات، مخططات مسموحة |
| Path traversal | `..` أو مسار مطلق/UNC خبيث | كتابة خارج المجلد | تطبيع، جذر تنزيل، رفض `..`، منع reparse |
| Command injection | اسم/معامل يفسره shell | تنفيذ أوامر | بلا shell، وسائط مصفوفة، تحقق |
| Malicious media | اسم/مخرج ffmpeg/yt-dlp | تلف/تجاوز | عزل، حدود، عدم تنفيذ |
| Browser bridge spoof | رسالة من إضافة غير معروفة | إنشاء مهام/تسريب | تحقق ID/حجم/حقول، لا منفذ |
| Silent capture | مراقبة تاريخ/تنزيلات | انتهاك خصوصية | فعل مستخدم، تعطيل افتراضي |
| Update takeover | تحديث/بيان مزيف | تنفيذ كود | توقيع، مصدر رسمي، رفض |
| Secret leak | cookie/token في سجل | سرقة جلسة | DPAPI، تنقية، منع سجلات |
| Malicious dependency | حزمة مخترقة | تنفيذ/تسريب | lockfile، مراجعة، فحص، SBOM |
| DoS محلي | روابط/أجزاء/سجلات ضخمة | تجميد/قرص | حدود، backpressure، تدوير |
| AI data leak | إرسال URL/headers لمزود | خصوصية | موافقة، تنقية، تعطيل |
| Malicious file execution | فتح ملف منزّل تلقائيًا | تنفيذ | لا فتح تلقائي، تأكيد |
| Tauri IPC abuse | أوامر من واجهة مخترقة | صلاحيات خاطئة | تحقق، capabilities ضيقة |
| Zip/disk bomb | ملف/صفحة ضخمة | استنزاف | حدود حجم/معدل/مساحة |

## 4. ثقة الشبكة

### 4.1 الروابط

- `http`/`https` فقط؛ رفض `file:`, `javascript:`, `data:`, `ftp:` في v1.
- حد الطول والترميز.
- منع `localhost`, `127.0.0.0/8`, `::1`, IP خاصة/محلية/link-local، metadata cloud.
- منع التحويلات إلى مخططات/عناوين ممنوعة.
- حد عدد التحويلات.
- DNS rebinding: تحقق من العنوان الفعلي عند الاتصال، لا مرة واحدة فقط.
- لا اتباع redirects تلقائيًا إلى نطاق غير متوقع دون تحقق.
- لا `Referer`/cookies إلا عند الحاجة وبقرار.

### 4.2 الطلبات

- مهلة اتصال/قراءة/كلية.
- حد حجم الاستجابة.
- `User-Agent` واضح.
- منع حقن CRLF في الترويسات.
- عدم تسجيل query كامل إن كان حساسًا.
- احترام `Retry-After` و`robots.txt` حيث ينطبق.
- لا تثبيت شهادات خاطئة؛ لا تعطيل TLS verification.

### 4.3 التزامن

- حد للمضيف/الكلي/المهمة.
- منع إغراق خادم/شبكة.
- backoff مع jitter.
- إلغاء لا يترك اتصالات مفتوحة.

## 5. الملفات والمسارات

- كل كتابة داخل جذر تنزيل محدد ومُتحقق.
- منع `..` والمسارات المطلقة من الواجهة.
- منع نقاط إعادة التحليل/symlink للهروب.
- أسماء محجوزة (`CON`, `NUL`, `COM1`...) تُنقّى.
- حد طول المسار وسلوك Windows الطويل.
- إعادة تسمية ذرية على نفس وحدة التخزين.
- تحقق حجم/بصمة قبل الإعلان عن الاكتمال.
- ملفات مؤقتة `.part` بصلاحيات مناسبة.
- لا تنفيذ/فتح تلقائي.
- الحذف صريح، ولا يحذف السجل ملفات.
- منع دهس ملف موجود دون تأكيد.
- أخطاء القرص/الصلاحية لا تُخفى.

## 6. العمليات الخارجية

- `yt-dlp`/`ffmpeg`/أدوات مشابهة:
  - وسائط مصفوفة، بلا shell.
  - `--ignore-config`/منع `--exec` حيث ينطبق.
  - مسار أداة مثبت/متحقق.
  - بصمة/إصدار موثق.
  - مهلة، حد مخرجات، قتل شجرة العمليات.
  - بيئة محدودة، لا أسرار في argv.
  - عدم تفسير stdout/stderr كأوامر.
  - مخرجات غير موثوقة تُعرض كبيانات.
- لا تشغيل ملف منزّل تلقائيًا.
- لا `eval`/`Function`/`exec` من نصوص.
- لا برامج نصية من المستخدم.

## 7. جسر المتصفح

- WebExtension فقط، لا منفذ localhost/استماع شبكي.
- Native Messaging عبر stdin/stdout.
- تسجيل في `HKCU` لكل مستخدم، ومسار/معرّف مسموح.
- تحقق من:
  - معرّف الإضافة/المضيف.
  - المخطط/الطول.
  - الحقول المعروفة فقط.
  - رفض الحقول الإضافية/المسارات/الأوامر.
  - حجم الرسالة.
- لا cookies/تاريخ تصفح/تنزيلات خفية.
- التقاط بفعل مستخدم فقط، وتعطيل افتراضي.
- معاينة/تأكيد قبل المهمة.
- إزالة التسجيل عند إلغاء التثبيت.
- العقد: [SYSTEM_ARCHITECTURE.md](SYSTEM_ARCHITECTURE.md).

## 8. الزاحف

- صفحة واحدة، HTML ثابت، نطاق أصلي، عمق 1، حد روابط.
- `robots.txt` و`User-Agent` وحد معدل.
- منع SSRF/العناوين الخاصة/التحويلات الخطرة.
- حد حجم الاستجابة والنوع.
- لا JS، لا cookies، لا جلسات، لا paywall.
- إزالة تكرار وتنقية.
- معاينة/تأكيد قبل التنزيل.
- إلغاء آمن.

## 9. التخزين والأسرار

### 9.1 قاعدة البيانات

- SQLite محلية بصلاحيات المستخدم.
- لا تخزين أسرار خام.
- `PRAGMA foreign_keys=ON` (موجود).
- WAL/busy_timeout/نسخ احتياطي **مقترح**، غير مفعّل حاليًا.
- ترحيلات إلى الأمام مع نسخة قبل الترقية.
- لا حذف تلقائي لملفات عند تلف DB.
- حماية من حقن SQL: استعلامات parameterized (موجودة).

### 9.2 الأسرار

- لا كلمات مرور/مفاتيح/شهادات في المستودع أو الاختبارات.
- DPAPI/Credential Manager للأسرار عند الحاجة.
- `secret_refs` مراجع فقط.
- لا أسرار في argv/URLs/سجلات.
- أي سر مكشوف يُعتبر محروقًا ويُستبدل.

### 9.3 الاحتفاظ والحذف

- سياسة معلنة للسجل/السجلات/التشخيص.
- حذف كامل من الواجهة: سجل، إعدادات، بيانات، أسرار.
- تصدير/حذف قابل للتحقق.
- لا نسخ خفية.

## 10. IPC والواجهة

- Tauri capabilities ضيقة (`core:default` حاليًا).
- لا وصول ملفات/شبكة مباشر من JS.
- أوامر typed، لا مسارات/أوامر خام.
- تحقق من الحالة والصلاحية.
- أخطاء منقحة لا تكشف مسارات/رموز.
- CSP:
  - الحالي: `default-src 'self'`، `img-src 'self' data:`، `style-src 'self' 'unsafe-inline'`، `script-src 'self'`، `connect-src ipc:`.
  - مراجعة `unsafe-inline` وتقليلها إن أمكن.
  - لا موارد بعيدة.
- لا `dangerouslySetInnerHTML` للمحتوى الخارجي.
- روابط خارجية تفتح في المتصفح بعد تحقق، لا داخل WebView.

## 11. التحديث والإصدار

- بناء من GitHub Actions فقط.
- توقيع كود إن توفر؛ وإلا إعلان غير موقّع.
- بيان تحديث موقّع (إصدار/رابط/بصمة).
- تحقق من التوقيع والمصدر قبل التثبيت.
- رفض التوقيع الخاطئ/الإصدار المسحوب.
- لا تثبيت أثناء تنزيل نشط دون تأكيد.
- تراجع بسحب الإصدار.
- SBOM/checksums/تراخيص.
- أسرار في GitHub Secrets فقط.
- بيئة release محمية وموافقة بشرية.

## 12. سلسلة التوريد

- lockfiles إلزامية (`pnpm-lock.yaml`, `Cargo.lock`).
- تثبيت إصدارات الأدوات.
- مراجعة أي اعتماد جديد: ترخيص، صيانة، شهرة، سطح هجوم.
- `cargo audit`/`pnpm audit`/SBOM (مقترح، غير موجود).
- فحص أسرار موجود (gitleaks).
- لا سكربتات بناء غير مراجعة.
- حدّث التبعيات بأمان، لا تلقائيًا في الإصدار.
- تراخيص `yt-dlp`/`ffmpeg` تُراجع قبل التوزيع.

## 13. السجلات والتشخيص

- لا cookies/tokens/passwords/headers حساسة.
- URLs منقحة أو مضغوطة.
- مسارات المستخدم لا تُعرض افتراضيًا.
- تدوير وحد حجم.
- تصدير محلي فقط.
- لا إرسال تلقائي.
- موافقة صريحة لأي قياس/تحليل.
- حزمة التشخيص تُفحص قبل المشاركة.

## 14. AI والخصوصية

إن اعتمد AI:

- تعطيل افتراضي، وليس شرطًا للتنزيل.
- موافقة صريحة لكل نوع بيانات.
- لا إرسال URL/headers/cookies/ملفات افتراضيًا.
- تنقية/تلخيص قبل الإرسال.
- عدم تخزين لدى المزود إن أمكن.
- توضيح المزود/التكلفة/الاحتفاظ.
- فشل مغلق.
- لا تنفيذ إجراءات تلقائية.
- سجل مكالمات منقح.
- مراجعة قانونية/خصوصية قبل التفعيل.

القرار في [OPEN_DECISIONS.md](OPEN_DECISIONS.md).

## 15. الخصوصية

### 15.1 المبادئ

- جمع الحد الأدنى.
- لا تتبع افتراضي.
- لا حساب/سحابة في v1.
- لا بيع/مشاركة بيانات.
- شفافية.
- حذف/تصدير.
- احتفاظ محدود.

### 15.2 البيانات المحتملة

| البيانات | الغرض | الاحتفاظ المقترح |
| --- | --- | --- |
| الإعدادات | تشغيل | حتى الحذف |
| سجل التنزيلات | عرض/إعادة | 90 يومًا افتراضيًا |
| مسارات الملفات | فتح/إدارة | مع السجل |
| سجلات تشخيص | دعم | 7 أيام/حد حجم |
| أسرار | مصادقة اختيارية | حتى الحذف/انتهاء |
| إحصاءات محلية | أداء | لا تُرسل |

هذه قيم مقترحة، وليست معتمدة.

### 15.3 حقوق المستخدم

- معرفة ما يُخزن.
- حذف السجل/البيانات.
- تعطيل الميزات الاختيارية.
- تصدير حزمة تشخيص.
- عدم إرسال أي شيء تلقائيًا.

3. أعد إنتاج الثغرة بأقل ضرر.
4. صنّف الخطورة والأثر.
5. أصلح وأضف اختبار انحدار.

8. استبدل أي سر مكشوف.
9. راجع السبب الجذري.

- عزل المحركات.
- أسرار مشفرة.
- جسر مغلق.
- تحديث موقّع.
- سجلات منقحة.
- خصوصية افتراضية.

- مراجعة بشرية قبل الإصدار.
