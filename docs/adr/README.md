# سجلات القرارات المعمارية (ADR)

كل قرار كبير له ورقة مستقلة: السياق، الخيارات، القرار المقترح، الأسباب، النتائج، وما يحتاج موافقة.

**الحالة الحالية:** اعتمد المالك الرخصة (0001)، ثم اعتمد قرارات الإطار واللغة والتخزين والترجمة والاختبارات (0002، 0003، 0005، 0006، 0009) عند موافقته على بدء المرحلة 1 في 2026-10-31. بقية الأوراق «مقترحة» بانتظار الموافقة. لا يُعتبر أي قرار مقترح نهائيًا قبل الموافقة.

## قالب ورقة جديدة

```text
# ADR-XXXX: العنوان
- الحالة: مقترح | مقبول | مرفوض | مستبدل
- التاريخ: YYYY-MM-DD
- القرار: ...
- الوثائق المرتبطة: ...

## السياق
## الخيارات
## القرار المقترح
## الأسباب
## النتائج
## قابلية التراجع
## ما يحتاج موافقة
```

## قواعد

- لا يُغيّر قرار مقبول بصمت؛ تُضاف ورقة جديدة أو يُحدَّث статус القديمة إلى «مستبدل».
- كل قرار كبير جديد (تغيير إطار، قاعدة بيانات، محرك، رخصة، سياسة تحديث) يحتاج ورقة.
- القرارات الصغيرة التنفيذية تُوثَّق في PR أو تعليق كود، لا في ADR.
- «لم يُختبر» تُكتب صراحة عند الادعاءات غير المثبتة.
